## Como rodar

Na raiz do repositório:

```bash
cd prog-c
gcc -Wall 1037.c -o 1037
./1037
```

É só trocar 1037 pelo número do exercício. Cada arquivo roda separado.
O `hello.c` é um exemplo das primeiras aulas e não está na lista.
Os executáveis ficam fora do Git.

Usei o Codex para ajudar nos 20 exercícios que faltavam e nos testes.
Os 24 programas compilaram e passaram nos testes locais; isso não é uma
confirmação de aceite no Beecrowd.
